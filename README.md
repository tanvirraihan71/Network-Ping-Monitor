# Network-Ping-Monitor
Lightweight Windows Network Monitoring Software for real-time IP/hostname ping monitoring, online/offline status, packet loss, response time, background monitoring, notifications, email alerts, and PDF/HTML reports. Ideal for IT admins, NOC teams, network engineers, servers, routers, switches, and ISP monitoring.
